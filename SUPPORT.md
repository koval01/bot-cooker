# Getting help

- **Documentation**: <https://koval01.github.io/bot-cooker/> covers deployment,
  configuration, operation and troubleshooting.
- **Questions and ideas**: open a
  [discussion](https://github.com/koval01/bot-cooker/discussions) or an issue
  with the *Question* template.
- **Bugs**: open an issue with the *Bug report* template and include the
  output of `bot-cooker --version` and `bot-cooker --check`. Leave out your
  master key and admin token.
- **Security problems and ways to recognise a trap**: report them privately,
  as described in [SECURITY.md](SECURITY.md).

This is a volunteer project; answers may take a few days.
